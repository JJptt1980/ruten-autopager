# 專案現況

## 目前進度
- v1.4：露天賣場自動翻頁 userscript（`ruten-autopager.user.js`），適用 `https://www.ruten.com.tw/store/*`。
- 2026-11-23 修好「捲動不順」三個問題：
  1. 載入中繼續往下捲，載完會被拉回開始載入的位置（一次跳回 2000～3800 px）→ 改成記住使用者捲到的位置。
  2. 露天每頁實際要 0.7～1.2 秒（不是以前量的 0.1 秒）→ 提早到剩 3 個螢幕高就載入。
  3. 翻幾十頁後畫面有幾千個商品、9 萬多個節點，每次換頁卡 0.1～0.3 秒 → 離畫面 3000 px 以外的舊頁先收起來（IntersectionObserver），捲回附近再放回。節點數 94k → 5k。

## 已定案的決定
- 不用 iframe，直接點露天自己的「下一頁」，前一頁商品複製保留在上方。
- 使用者只信任這 6 家（詐騙多），比價／總覽只抓這 6 家。
- 露天賣場最多只顯示 134 頁（約 4000 件）。
